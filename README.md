# Anthropic Economic Index Capstone Project

## Dataset

This project uses multiple releases of the Anthropic Economic Index to study how the difference in automation-oriented AI usage between Claude.ai and the Anthropic first-party API changes over time.

The primary analysis uses the following compatible releases:

- September 15, 2025
- January 15, 2026
- March 24, 2026

**Dataset Source:**
https://huggingface.co/datasets/Anthropic/EconomicIndex

## Research Question

**How has the difference in automation-oriented AI usage between the API and Claude.ai changed over time when comparing the same types of tasks?**

## Hypothesis

**We hypothesize that the difference in automation-oriented AI usage between API and Claude.ai will decrease over time when comparing the same tasks.**

Which Economic Tasks are Performed with AI? Evidence from Millions of Claude Conversations
